What do these match types mean?
exact
The query sequence and the stored sequence are identical after normalisation; same hash, so the same allele, whatever either is called.
substring
One sequence is fully contained in the other: your query is a fragment of this allele, or this allele is a fragment of your query. No mismatches.
similar
Neither exact nor contained: ranked by % identity (how it is computed). Read the Identity column with it.
name
Matched on a label, not on sequence. A name match says nothing about the sequence; the same name denotes different sequences in different species.
cached
Served from the precomputed neighbour cache. Same identity calculation, computed ahead of time.
protein_uid
Matched a protein UID: these V alleles differ in nucleotide sequence but translate to the same amino-acid sequence.
superseded
Not a match type but a record status: IMGT has since published this allele at a different extent. The tag links to the current record.
