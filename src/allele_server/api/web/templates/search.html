About AIRBabel

AIRBabel aggregates immunoglobulin and T-cell receptor allele reference data from IMGT, OGRDB and curated sets. Records are identified by sequence rather than by name, so a name from any contributing source resolves to one canonical germline identity carrying its aliases, leader, RSS and cross-species neighbours. It complements the primary databases and does not adjudicate nomenclature.

Data: IMGT (CC BY 4.0), OGRDB and published sources, each credited on Sources & citations. What AIRBabel adds → · Download the dataset →
