# About this repository

This repository is **generated**. It is the public subset of the AIRBabel server that
runs at <https://airbabel.org> — the web application, REST API, MCP endpoint, identity
primitives, database schema, ingestion pipeline and source manifests.

It is published as a content snapshot, one commit per sync, so it carries no
development history. Each commit message names the upstream commit it was built from.

**Do not commit here.** Anything pushed directly to this repository is overwritten by
the next sync. Please open an issue instead, and say which file you are looking at.

Not included: deployment configuration, internal planning material, curated data files
and caches. The dataset itself is downloadable from the API — see `DATA-README.md` and
<https://airbabel.org/api/export>.
